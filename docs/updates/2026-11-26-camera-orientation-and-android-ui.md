# 眼镜画面方向与 Android 界面

## 本轮目标

校正眼镜画面的左右方向，改善随身助手的界面和操作层次。

## 改动

- 电脑直连 ESP32 和手机上传快照均在服务端水平翻转。Android 原生预览水平显示原始快照，原始字节交给电脑处理。模拟素材和用户上传图片按原方向显示。
- Android 0.5 使用深色卡片界面，将连接设置和快速问答分组。完整助手使用相同配色，突出开启语音与主要操作。连接与快速问答各自显示反馈。

## 验证

- 134 项自动测试通过。用左右双色 JPEG 验证电脑直连预览、手机快速问答和完整助手的视觉输入方向。
- Android 模拟器安装 APK 0.5，按截图像素确认原生相机预览翻转，验证通过本地 HTTPS 打开完整助手、取图问答、模拟路线确认并开启连续原生录音。
- vivo 上实际眼镜的画面方向与现场交互仍待确认。
