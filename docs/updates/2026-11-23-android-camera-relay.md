# Android 随身取图与宿舍电脑问答

## 本轮目标

让手机连接眼镜热点，从眼镜现有的 MJPEG 流取一张图，通过可达的 HTTPS 地址送给宿舍电脑。第一阶段交付手机取图、文字及语音视觉问答。手机端的传感器转发和高德导航属于后续阶段。

## 安装和操作

1. 手机在能访问电脑的网络下，下载 [3800 Android 安装包](https://10.4.162.20:8443/api/mobile/apk)。用户名为 `3800`，口令使用项目本地 `.env` 的 `WEB_ACCESS_PASSWORD`。也可把电脑上的 `artifacts/android/3800-mobile.apk` 通过 USB 复制到手机。支持 Android 9 及以上。
2. 确认手机信任签发 3800 服务器证书的 CA。已有适用 CA 可以继续使用，服务器证书中的 IP 或主机名需与 App 填写的地址一致。
3. 打开 vivo 的 2.4 GHz 热点，让眼镜连接。眼镜本次取得的局域网地址可通过热点客户端列表或串口查看。App 中填写眼镜地址，点击「测试眼镜取图」。成功后会显示一张画面，这一步的画面保留在手机。
4. 填写宿舍电脑的 HTTPS 地址和口令，点击「测试电脑连接」。在手机可以直接到达宿舍校园网地址时，使用上面的地址。移动数据或校园网隔离环境下，需要可达的私网地址或学校提供的远程接入，并给实际使用的地址配置匹配证书。
5. 使用「发送文字问题」，或点击「开始录音」说话，再点「结束录音并发送」。每次问答读取一张眼镜快照。使用云视觉时勾选当次发送许可。App 显示问题与答案，电脑提供合成音频时由手机播放。

## 实现

- Android 原生取图使用眼镜现有的 `/stream`，按固件的 multipart 边界和 `Content-Length` 读取单个 JPEG。眼镜地址限制为局域网 IPv4，源连接不跟随重定向。
- 电脑端 `/api/mobile/status`、`/api/mobile/ask` 和 `/api/mobile/apk` 需要 HTTPS 和已配置的访问口令。问答请求按 4 字节大端 JPEG 长度、JPEG、UTF-8 文字或 16 kHz 单声道 16 位 PCM 封包，JPEG 上限 1 MiB，录音上限 10 秒。复用现有视觉、SenseVoice 和语音合成服务。快照限于本次请求，不替换控制台相机，也不写磁盘。
- App 只记住两个地址，口令保留在当前界面。手机证书通过系统和已信任的用户 CA 校验。
- 本地构建使用 JDK 11、Android SDK Platform 34、Build Tools 34.0.0、`zip`。运行 `ANDROID_SDK_ROOT=/实际/SDK/目录 bash android/build.sh`，本机也可直接运行 `bash android/build.sh`。安装包与开发签名保存在 Git 忽略的 `artifacts/android/`。

## 验证与待验收

- APK 已构建并通过签名验证。129 项 pytest 通过，覆盖手机请求授权、错误图片、大小限制、云视觉授权和手机画面与电脑相机的隔离。
- 用合成 MJPEG 流和固定录音运行 Android 客户端的 Java 网络组件，验证取图、HTTPS、普通话识别、答案和 WAV 返回。
- Android 9 模拟器已安装最终 APK，验证相机预览、密码遮盖、认证 HTTPS、文字问答回显，以及录音无语音时的重试提示。
- 校园网 HTTPS 服务已重启，验证匿名下载返回 401，已认证下载与本地 APK 字节一致。使用合成蓝色杯子验证现有真实视觉服务返回「图中的杯子是蓝色的」并生成播报。
- 待验收 vivo 开着热点时两条网络能否同时使用，以及真机录音和播报。当前宿舍电脑地址已在校园网监听，跨校园和移动数据的可达性取决于实际网络。
