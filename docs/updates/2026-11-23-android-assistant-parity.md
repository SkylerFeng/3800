# Android 接回网页语音助手

## 本轮目标

恢复 APK 中的助手对话、地点候选、路线确认和高德跳转，让手机继续从眼镜热点取图。

## 改动

- Android 0.2 增加「打开完整语音助手」，在 App 内打开 3800 的助手页。复用现有连续语音、导航会话、定位权限、高德跳转和播报流程。设置页可以单独测试眼镜和电脑，并显示连接、证书或登录错误。
- 电脑识别到视觉问答后才向手机请求一张 JPEG。手机从眼镜热点读取图片并回传，导航指令无需取图。一次性的取图请求与当前助手会话绑定。取图失败时，Agent 仍能处理同一条指令中的其他任务。
- 复现并修复了 Android WebView 打开页面后，后续接口请求缺少登录凭据的问题。App 使用现有口令通过 HTTPS 建立网页会话。取图时使用手机的局域网连接，服务器 HTTPS 使用正常的 CA 验证。

## 操作

1. 用 0.2 版本覆盖安装，在设置页填写眼镜 IP、电脑 HTTPS 地址和口令。灰色示例仅提示格式。
2. 点「测试电脑连接」确认手机能访问电脑。点「打开完整语音助手」进入对话。导航权限和图片权限可在助手页开启。
3. 说「导航到图书馆」或输入同一句话，再选择候选、确认出发。视觉问答前，让眼镜连上手机热点并测试取图。

## 验证

- 131 项 pytest 通过，覆盖手机登录、请求快照、快照只用一次、音频入口选择候选以及取图失败后继续处理其他指令。
- Android 9 模拟器安装 0.2 APK。使用合成 MJPEG 和模拟地图，在 App 内完成登录、视觉问答、搜索图书馆、选第一个、确认出发。服务日志显示只有视觉问答上传了快照。
- vivo 的现场连续录音、定位和高德 App 拉起待真机验证。移动时仍需手机能访问宿舍电脑。随身模式的 IMU 和声纳转发尚待接入。
