# 迭代 9 · 网页授权与导航衔接

本轮目标是在同一个手机浏览器地址上减少重复设置，并让用户通过语音填写目的地、结束项目内导航和继续对话。

- 助手新增「权限与设置」。用户可以选择记住画面、位置和城市设置，也可以清除这些偏好。手机浏览器管理麦克风和定位系统权限。
- 语音识别出的目的地自动填入可编辑的搜索框。可以在助手内搜索候选，也可以用带关键词的高德链接查看地点。
- 助手在接近目的地时播报提醒，用户说「确认到达」后结束路线。助手会话继续运行。
- 校园网服务新增访问口令和 `--require-access` 启动选项。电脑当前校园网 IP 的证书由原项目 CA 签发。

122 项自动测试通过。Chrome 已验证刷新后保留设置、撤销设置、目的地填入和手机宽度布局。电脑确认校园网地址支持 HTTPS、匿名请求返回 401、正确登录后返回 200。

待验收项目包括校园网手机到电脑及电脑到 ESP32 的连通性、vivo 实机语音导航、独立高德 App 结束后的返回机制，以及无需电脑的 Android 运行方案。

操作步骤见 [导航配置](../NAVIGATION_SETUP.md) 和 [演示说明](../DEMO.md)。
