# 导航返回与视觉追问

## 本轮目标

先留档当前可用版本，再改进从高德切回 3800 后的体验，并支持对同一物品连续提问。

## 改动

- GitHub 的 main 已留档 APK 0.3 对应源码，提交为 495352d。
- APK 0.4 从 3800 启动独立高德步行导航后，切回助手会恢复此前已开启的连续录音。高德未提供本项目所用步行入口的导航结束回调，用户通过返回手势或最近任务切回 3800。3800 内置路线仍可用「确认到达」结束并继续对话。
- Agent 在当前会话记住用户明确询问的单个目标名称，例如杯子。追问「它在哪」会用新眼镜画面识别。电脑直连实时摄像头时会等待新帧，手机端每次视觉问答按需重新取图。新会话清空目标，缺少明确指代时请用户说出物品名称。

## 验证与待验收

132 项自动测试、JavaScript 语法检查及 APK 签名验证通过。回归测试验证追问会把新帧与补全后的问题一起送给视觉模型，并验证新会话不会继承目标。独立高德 App 返回后的录音恢复待 vivo 真机验收。
