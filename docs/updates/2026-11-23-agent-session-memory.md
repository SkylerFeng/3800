# Agent 会话记忆与功能调度

## 本轮目标

让用户在视觉问答、测距和导航之间切换后，还能追问之前谈过的物品或继续当前路线。

## 实现

- Agent 按最近一次询问的顺序保留最多八个明确的视觉目标及其最近用过的帧编号。用户可以说「它在哪」「上一个物品在哪」或直接说出之前的物品名称。导航、测距和一般场景问答会保留这组记录。新会话从空记录开始，当前默认有效期为 15 分钟。
- 追问用当前图像判断位置。手机端按需重新取图。电脑直连实时相机遇到同一帧时，会等候新的画面。指代含糊时请用户说出目标名称。
- 同一条指令可以按顺序调用最多三个功能。文本和语音输入使用同一个 Agent，会话内分别维护视觉目标、地点候选和路线进度。地图路线来自高德或演示地图，用户单独确认出发或更换目的地。声纳预警由规则计算，电脑收到近障数据时会暂停 3800 的具体转向播报。

## 验证

- 132 项自动测试通过。回归覆盖先找杯子、插入地图搜索和测距、再切回视觉目标，以及继续选择并开始之前的路线。手机端回归覆盖追问重新上传快照。
- 使用模拟提供方验证跨模块流程。真实眼镜画面、高德 App，以及尚未接入手机的 IMU 与声纳转发需分别验收。
